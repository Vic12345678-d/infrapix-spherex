Infrapix

A public tool for exploring real SPHEREx sky images and spotting objects that move over time.

Use the tool How it works

SPHEREx Explorer

Connected to the live backend. Data is downloaded directly from NASA/IPAC IRSA.

Type an object name (or RA/Dec) inside the tool and press Find. Anything that moves or changes brightness between images shows up as a red spot (brighter) next to a blue one (fainter) in the right panel. The first load of an object can take several minutes.

The Challenge

SPHEREx maps the whole sky every six months in 102 bands of near-infrared light.

🌌

Over a billion objects

Stars, asteroids, comets, brown dwarfs and galaxies. Many move between observations.

👁️

Comparing over time

Objects like Pluto were discovered by comparing images taken at different times.

👥

Citizen science

A public tool is needed so anyone can explore SPHEREx.

How it works

Enter an object

A name (SIMBAD) or RA / Dec. Its proper motion is looked up.

Query IRSA

All SPHEREx exposures covering that position are found.

Download and align

FITS cutouts are downloaded and aligned onto the same sky grid.

Blink Comparator

Images are shown in sequence, with the motion path and the difference from the average.

Recommended objects

Barnard's Star

Large proper motion (about 10″ per year). Ideal for testing motion detection.

Epsilon Indi B

A pair of nearby brown dwarfs.

WISE 0855

A fast-moving brown dwarf.

RW Aurigae and R Draconis

Variable stars (brightness changes).
